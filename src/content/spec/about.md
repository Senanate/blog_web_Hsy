## 关于本站

本站使用 Astro 构建，主题基于 saicaca 的开源项目 Fuwari，代码托管于 GitHub，已经通过 Cloudflare Workers 上线。

推送到 GitHub 的 `main` 分支后，Cloudflare 会自动构建并部署更新。文章使用 Markdown 编写，站内搜索由 Pagefind 在构建时生成。

- 阅读完整搭建过程。[使用 Astro、Fuwari 和 Cloudflare 发布我的个人博客](/posts/astro-fuwari-cloudflare-blog/)

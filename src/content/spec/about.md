# 关于我

你好，我的英文名是 **SunnyHuang**，也可以在 GitHub 上找到我 **Senanate**。

欢迎来到我的个人博客。这里分享项目实践、博客搭建经验和学习笔记，也记录生活中的想法。我希望把做过的事情、遇到的问题和解决过程写清楚，方便自己回顾，也给遇到类似问题的朋友一些参考。

## 关于本站

本站使用 Astro 构建，主题基于 saicaca 的开源项目 Fuwari，代码托管于 GitHub，已经通过 Cloudflare Workers 上线。

推送到 GitHub 的 `main` 分支后，Cloudflare 会自动构建并部署更新。文章使用 Markdown 编写，站内搜索由 Pagefind 在构建时生成。

- 访问线上博客。[SunnyHuang 的博客](https://blog-web-hsy.hshu96260.workers.dev/)
- 阅读完整搭建过程。[使用 Astro、Fuwari 和 Cloudflare 发布我的个人博客](/posts/astro-fuwari-cloudflare-blog/)

感谢开源作者的分享。[Fuwari 主题](https://github.com/saicaca/fuwari)
